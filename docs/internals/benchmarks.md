## Reproductibilité des Benchmarks

Vous pouvez réexécuter vous-même la suite de benchmarks officielle à tout moment :

```bash
bun run bench
```

Pour enregistrer une baseline de référence et comparer vos futures modifications :

```bash
# Sauvegarder les résultats de la version actuelle
bun run bench:save

# Comparer automatiquement avec la baseline
bun run bench:compare
```
